# Bevia Desktop — Releases

Official releases of **[Bevia](https://bevia.co)** Desktop: signed
installers for macOS (universal `.dmg`, notarized) and Windows
(`.msi` / `.exe`), plus the auto-updater artifacts.

This repository holds installers and release metadata only — the code
lives elsewhere. If you can read this, you're in the right place to
download; everything about what the app *is* lives at
[bevia.co](https://bevia.co).

## Install

Grab the latest release from the
[Releases page](https://github.com/NeuroverseOS/bevia-releases/releases):

- **macOS** — download the `.dmg`, open it, drag Bevia to Applications.
- **Windows** — download the `.msi` (or `.exe`) and run it.

The app updates itself from this repository once installed.

## What Bevia is

Bevia turns observed work — your notes, your projects, your thinking
with AI — into a navigable, queryable map, built entirely on your own
machine. Your map is plain markdown on your own disk; nothing is
uploaded to Bevia.

- **Try it free** — point it at one folder and watch your map form.
- **Own it** — one payment at [bevia.co/local](https://bevia.co/local),
  yours forever, on up to 10 of your devices.

## Building a sensor?

The capture wire format is open:
[NeuroverseOS/bevia-protocol](https://github.com/NeuroverseOS/bevia-protocol)
— if you can write a JSON file, you can feed a Bevia engine.
