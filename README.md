# Bevia — Releases

Installers for **[Bevia](https://bevia.co)**, in beta. This repository holds installers and release metadata only.

## Install

Download from [bevia.co](https://bevia.co/#download), or from the
[latest release](https://github.com/NeuroverseOS/bevia-releases/releases/latest):

- **Mac (Apple chip)** — `Bevia-AppleSilicon.dmg`. Open it and drag Bevia to Applications.
- **Mac (Intel)** — `Bevia-Intel.dmg`.
- **Windows** — `Bevia-Windows-Setup.exe`. Windows may say it protected your PC: choose **More info**, then **Run anyway**.

Bevia updates itself from this repository once installed.
